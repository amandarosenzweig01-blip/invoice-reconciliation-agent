## Running it

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env    # then fill in your keys
python run_eval.py --variant baseline
streamlit run app.py
```

Regenerating the PDF corpus (`python tools/generate_corpus.py`) uses
WeasyPrint, which needs Pango (`brew install pango`). On Apple Silicon Macs,
Homebrew's libraries aren't on the default search path, so also run:

```bash
export DYLD_FALLBACK_LIBRARY_PATH=/opt/homebrew/lib:$DYLD_FALLBACK_LIBRARY_PATH
```
